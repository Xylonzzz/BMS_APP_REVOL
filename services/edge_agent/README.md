# REVOL Edge Agent

`CaptureWorker` 将只读输入保存为 `frames.jsonl`，再由共享协议聚合器生成 `snapshots.jsonl`。文件输入保留记录时间和原序号；实时 CAN 使用主机接收时间。主机接收证据不代表固件采样有效。

## 文件输入限额

- 接受 UTF-8（可带 BOM）的原帧 JSONL 或包含 `frames` 数组的快照 JSONL。
- 每行最多 **16 MiB（16,777,216 字节，包含换行）**；单个快照最多 **10,000 帧**。超限会报告文件与行号，不截断后继续解析。
- 每次接收最多返回调用者指定的帧数；采集 worker 每批为 100 帧。遇到坏行或超限行时，已读取的合法前序帧先交付保存，下一次接收明确报错。
- 原始输入不可同时作为输出；新采集拒绝非空会话目录中的记录文件。

## 并发读取

快照分页最多返回 200 条。读取开始时固定文件大小并确认完整末行，随后释放采集共享锁扫描历史；后续追加不会混入当前页，浏览历史不会长时间阻塞原帧写入。导出同样按固定边界读取，保留原始文件。

验证使用假适配器与文件记录。真实 USB-CAN 设备、驱动和接线仍需单独实测。
