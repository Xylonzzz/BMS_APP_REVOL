# 第一阶段运行说明

## 已完成

- 共享 TypeScript 数据合同：`packages/bms-contracts/types.ts`
- 信号树和 WebSocket 事件 JSON Schema：`schemas/`
- 可重复模拟 BMS 会话：`services/edge_agent/simulator.py`
- PEC 错误注入：保留原始数值，设置 `valid=false`、`quality=pec_error`，并产生 `CELL_PEC_ERROR` 诊断事件
- JSONL 不可变会话记录：`services/edge_agent/session_store.py`
- 只读 HTTP API：`services/api_server/server.py`
- 浏览器监控页面：`apps/web/`
- 回放场景 API：`/api/v1/replay/scenarios` 和 `/api/v1/replay/scenarios/{name}`
- AF/EF 自动识别：保留旧上位机边界槽和温度槽语义，增加证据、质量、自动/手动来源
- 浏览器页面已参考原上位机 `BMS_STATE`、`Cell_Vol_1/2`、`Cell_Tem_1/2`、`realy_charge`、`Threshold_Value1`、`CAN` 和 `Test_Control` 的页面语义建立导航
- Engineering、Operations、Minimal 三种主题
- `prefers-reduced-motion` 和错误状态红色显示

## 启动 API

在 `D:\BMS\BMS_APP_REVOL` 执行：

```powershell
python services/api_server/server.py --port 8765 --data-dir runtime/demo
```

然后可访问：

- `http://127.0.0.1:8765/api/v1/health`
- `http://127.0.0.1:8765/api/v1/snapshots/latest`
- `http://127.0.0.1:8765/api/v1/diagnostics`
- `http://127.0.0.1:8765/api/v1/replay/scenarios`
- `http://127.0.0.1:8765/api/v1/replay/scenarios/af`

## 启动浏览器端

另开一个终端：

```powershell
python -m http.server 4173 --directory apps/web
```

浏览器打开 `http://127.0.0.1:4173`。页面会默认显示一个 PEC 错误单体，用于验证“有数字但无效”的显示路径。左侧导航沿用原上位机的主要页面分区，当前温度、阈值和继电器控制页面是只读预览。

顶部“回放”可加载 `valid`、`pec_error`、`partial`、`timeout_stale`、`disconnected_reconnect`、`af`、`ef` 和 `mixed_model`。型号选择可模拟旧上位机的 AF/EF 手动覆盖；自动识别只有在电压边界槽 `17,35,...,125` 与温度槽 `48..69` 证据收齐且质量有效时才切换。
