## 启动浏览器端

另开一个终端：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory apps/web
```

浏览器打开 `http://127.0.0.1:4173`。首次使用空数据目录时生成一条含模拟 PEC 错误的快照，此后读取该记录；没有连续采集任务，刷新也不会生成新采样。`runtime/demo` 是历史证据，保持不变；本轮使用独立数据目录。当前温度、阈值和继电器页面是功能占位。

省略 `--data-dir` 时使用 `runtime/live-check/current`。显式读取旧0.1模拟记录时，缺少帧外质量元数据的解码标为unknown，不把字节可解析认定为采样有效。源码更新后如页面仍显示旧内容，请强制刷新浏览器缓存。

顶部“回放”可加载 `valid`、`pec_error`、`partial`、`timeout_stale`、`disconnected_reconnect`、`af`、`ef` 和 `mixed_model`。加载后显示第一条，用上一条/下一条逐步查看：partial 与 timeout 各两步，断线重连为正常、断线、恢复三步。页面显示步骤、记录时间、序号；槽位详情保留值的原始时间与序号，断线步骤没有新帧。

手动 AF/EF 是独立的视图覆盖，恢复自动后回到原识别结果。自动识别检查质量、连接及所需证据的时间与序号；不足时为 unknown，或保留上一型号并降低置信度。API 请求失败时保留旧值但明确标记失联，不能当作当前采样。回放模式禁用“分析 API 最新快照”，避免分析对象错位。

当前模拟输出为 144 软件槽，其中每模组第 18 槽标记 `physicalValid=false`，共 136 个物理槽。AF/EF 场景只用于验证历史识别语义；EF 场景会向保留槽注入非零特征，不改变物理电池配置。`totalVoltage` 是 144 软件槽的模拟累压，单位 mV，包含保留槽特征值；`current` 为合成电流，单位 A。它们不是已接入硬件的 ADC 或电流测量。

72 路温度使用 `source=synthetic-model-evidence`，其中扩展槽用于 AF/EF 测试；活动固件只有 48 路温度遥测。PEC 来自 `qualityMetadataSource=simulation` 与 `signalQualities` 帧外注入，真实 CAN 字节没有这些有效性字段。接收记录时间与模拟批次不代表固件已经上送采样时间和序号。
