# 模组工作台视觉重设

用户要求尽可能发挥审美能力并按实际模组数量分隔单体电压。本轮直接实现可运行设计，延续既有只读、质量及回放语义。

## 设计方向

- 陶瓷白 `#F3F6FB`、面板白 `#FFFFFF`、海军蓝 `#16324F`、钴蓝 `#315FEA` 构成界面；有效用青绿 `#21856B`，警告用琥珀 `#A9670A`，故障用红 `#C9434B`。
- 标题使用 Manrope，正文使用系统中文字体，数值使用 JetBrains Mono；本地后备字体保证离线可读。
- 深蓝窄导航、顶部会话工具栏、主工作区和证据侧栏。总览以电池模组地图为核心，单体页显示每模组独立的编号、范围、压差及电芯网格。
- 特征元素是带物理编号的模组托盘：总览用压缩电芯条，单体页完整展示。编号表示实际模组/通道，保留槽使用明确的空槽外观。
- 点击单体打开质量、时间、序号和帧引用；异常显示原始数值。统计只使用有效物理电芯，失联时不输出可信范围/压差。

## 实现边界

1. CellVoltage增加可选moduleIndex/channelIndex（0-based）；模拟器按18软件槽一模组生成。布局由元数据和历史source字段确定，数量不在页面写死。
2. 新建共享前端模组渲染器，供总览和单体页复用；未知来源归未分组，不臆测物理拓扑。
3. 重写HTML/CSS并整合现有回放、型号覆盖、分析及质量状态。浅色为主设计，深色保留为可切换外观。
4. 运行模组分组/统计回归、既有Web状态测试、Schema及Python测试；浏览器验证宽屏、窄屏、分组数量、异常单体和回放。

本轮只涉及REVOL展示与可选模拟元数据，不改变固件、CAN载荷或硬件行为。旧JSONL保留；回退按本轮文件差异恢复。前一轮未提交改动继续保留。
